## 1. 设计哲学

### 1.1 双倒计时张力
两条倒计时同时压在玩家身上：
- **年龄倒计时**（20→100，不可逆）：给整关一个硬性时间预算，倒逼玩家不能无限试错。
- **回溯窗口倒计时**（8→1 秒，随年龄缩短）：每次回溯能"改变过去"的范围越来越窄。

关卡设计要让玩家**同时感受到两条压力**，而不是只用其中一条。

### 1.2 教学递进原则（来自 `GJBrainStorm_1.md` §6）
- 每关引入 **1 个新机关**，由浅入深。
- 新机关必须先用"必经路径"教学一次（玩家不操作就会经过），再用"解谜"强化一次。
- 不在同一关塞两个全新机关。

### 1.3 回溯解谜的三个心智层次
关卡难度按这三层递进，对应 5 关的分布：

| 层次 | 玩家要理解的 | 出现关卡 |
|---|---|---|
| L0：回溯改变**自己** | 倒带回到刚才的位置，穿墙 | L1 |
| L1：回溯改变**机关状态** | 水倒流/冰消融/尖刺收回，打开当下通路 | L2、L3 |
| L2：回溯改变**机关后，机关又触发新机关** | 倒带改变水流 → 水流重新触发压力板 → 弹簧启动 | L4、L5 |

### 1.4 关卡长度与时间预算
按 `agePerSecond` 默认 1，20→100 岁有 **80 秒**。每关给玩家的"满血通关时间"目标：

| 关 | 目标通关时间 | agePerSecond 建议 | 实际年龄预算 | 备注 |
|---|---|---|---|---|
| L1 教学 | 60-90 秒 | 0.5 | 160 岁（用不完） | 教学关宽松，几乎不会老死 |
| L2 | 70-100 秒 | 0.7 | ~114 岁 | 略紧，新手可能老死一次 |
| L3 | 90-120 秒 | 0.6 | ~133 岁 | 谜题复杂但时间松一点 |
| L4 | 80-110 秒 | 0.8 | ~100 岁 | 最紧，逼玩家用回溯加速赶路 |
| L5 综合 | 100-140 秒 | 0.7 | ~114 岁 | 综合关，时间中等 |

> 这些 `agePerSecond` 只是**初值建议**，实搭后必须 Play 测试微调。`DifficultySettingsSO` 已支持按场景配置（`AgeManager.cs:44-55`）。

## 3. 各关详细大纲

### L1 —— 回溯教学关（TeachingLevel01）

**目标心智**：L0——回溯改变自己。

**布局骨架**（横向，单层为主）：
```
起点 ──平地──┐                          ┌──高台── 出口
              │   一道穿不过的墙/深坑    │
              └──────────────────────────┘
                    ↑ 玩家必须回溯穿过
```

**段落分解**：
1. **段 A（必经教学）**：起点出发，平地走 3-4 屏。中间放一个**只回溯能过的障碍**——例如一道实心墙挡路，墙后是出口。玩家走到墙前发现无路，第一次按 R 倒带 → 但倒带只是回到过去位置，**墙在过去也是墙**。
   - ⚠️ 这是个反直觉点，需要处理：教学关应让玩家理解"回溯=回到自己的过去位置+穿墙"。
   - 正确教学：障碍设计成**玩家先穿过去再倒带**。即：玩家从高处跳下→落到坑底→倒带回到坑边的高台→此时取消碰撞可穿越。
2. **段 B（强化）**：放一个需要"倒带穿墙"的窄通道，引导玩家第二次使用回溯。
3. **段 C（出口）**：到达出口。

**关键设计点**：
- 本关**不放任何致死机关**（`GJBrainStorm_1.md` §6 L1 要求）。
- 不引入水流/冰块/尖刺，让玩家专注学回溯。
- 年龄增速调到 **0.5**，确保几乎不可能老死，避免教学关挫败感。
- 加一个 `RewindGuideTrigger`（已实现，`Triggers/RewindGuideTrigger.cs`）做文字引导："按住 R 倒带"。

**对应草图**：草图里的"教学/平地区"应是本关。

### L2 —— 死亡压力关（NormalLevel01）

**目标心智**：L1 入门——回溯改变自己 + **死亡是真实的**。

**新机关**：陷阱尖刺 `TrapSpike`（致死，`Spike/TrapSpike.cs`）。

**布局骨架**：
```
起点 ── 平地+地面尖刺(必经) ── 跳跃序列 ── 尖刺走廊 ── 出口
         ↑ 第一次见死            ↑ 回溯躲      ↑ 综合考验
```

**段落分解**：
1. **段 A（死亡教学）**：地面一片陷阱尖刺，玩家走过必踩 → 第一次暴毙 → 重开后理解"尖刺=死"。
   - 设计技巧：尖刺密度让玩家**正常走必死**，必须跳过；跳跃距离刚好需要助跑。
2. **段 B（回溯躲尖刺）**：一段连续尖刺走廊，玩家冲过去时被扎 → 倒带回起点 → 这次预判跳跃节奏。
   - 核心：让玩家意识到**回溯可以撤销死亡前一刻的错误**（虽然暴毙会直接重开，但回溯能在"快死"时救命）。
   - ⚠️ 需要确认：暴毙是瞬间触发还是受伤判定？看 `DeathManager.cs` / `HealthManager.cs` 决定段 B 的具体设计。
3. **段 C（出口）**：综合跳跃 + 少量尖刺。

**关键设计点**：
- 第一次引入 `DeathType.UnnormalDead` → GameOver 显示 "Slaughtered without mercy!"（`工作记忆.md` 已核实）。
- 年龄增速 **0.7**，比 L1 紧，让玩家感到时间压力。
- 段 B 是本关情绪高点："啊原来回溯能救命"。

### L3 —— 流水结冰关（新建 Level03）

**目标心智**：L1 核心——回溯改变**机关状态**。

**新机关**：
- 水源 + 水流 + 冻结（`Gameplay/Water/WaterSource.cs` + `Gameplay/Ice/Ice.cs`）
- 压力板（`Water/PressurePlate.cs`）
- 独立冰块（`Gameplay/Ice/IceBlock.cs`，地图摆放式）

**布局骨架**：
```
                    ┌── 水源(从上往下流) ──┐
起点 ── 平地 ── 高台 │  水流落下          │ 压力板(被水触发) ── 门 ── 出口
                    └────────────────────┘
                         ↑ 水会结冰变阻挡
```

**核心谜题**：
- 水从水源流下，玩家如果直接走会被水流冲到坑里 / 或水结冰挡路。
- 解法 A：让水流到压力板触发开门 → 但水流过程中会结冰挡路。
- 解法 B（引入回溯）：等水结冰后踩冰块跳上高台 → 再回溯让冰消融 → 水重新流动触发压力板。
- **关键瞬间**：玩家理解"回溯能让冰变回水、水变回冰"。

**段落分解**：
1. **段 A（水源教学）**：玩家走到 `WaterFlowTrigger`，水开始流。水流到地面结冰形成冰块 → 玩家踩冰块跳上高台。这是"水→冰"的第一次教学。
2. **段 B（冰→水教学）**：高台上有独立冰块挡路 → 玩家发现过不去 → 回溯 → 冰消融（或冰被回溯成水）→ 通过。
3. **段 C（综合谜题）**：水+冰+压力板组合，需要玩家**回溯切换水/冰状态**来交替触发压力板。

**关键设计点**：
- 必须让玩家**看到水结冰的过程**（不是一开始就是冰），否则"回溯改变机关"的教学不成立。
- 年龄增速 **0.6**，给玩家思考时间（这一关谜题重于操作）。
- 这一关是"回溯解谜"心智的正式建立点，难度可以稍高，但不要在操作上刁难。

### L4 —— 赶路与弹簧关（新建 Level04）

**目标心智**：回溯后的**加速 buff**用于赶路 + 弹簧 + 可拾取尖刺破坏冰块。

**新机关**：
- 弹簧 `BounceSpring`（`Spring/BounceSpring.cs`）
- 可拾取尖刺 `PickupSpike`（`Spike/PickupSpike.cs`，装备头上破坏冰块）

**布局骨架**：
```
起点 ── 长距离平地(需加速) ── 弹簧 ── 高空 ── 冰块墙(需尖刺破) ── 出口
         ↑ 用回溯加速              ↑ 弹起     ↑ 用拾取的尖刺
```

**核心机制教学**：
1. **回溯加速赶路**（`PlayerMovement.cs:29-31`）：段 A 是一段长平地，玩家如果正常走会老死在半路。解法：故意回溯一次（哪怕没意义），获得 1.5× 速度 buff 赶路。
   - ⚠️ 这个设计有风险：玩家可能不知道"回溯有加速奖励"。需要在段 A 之前用 `RewindGuideTrigger` 文字提示："回溯后会暂时加速"。
2. **弹簧**：段 B 用弹簧把玩家弹到高空平台。
3. **可拾取尖刺破冰**：段 C 高空有冰块墙挡路 → 路上捡到 PickupSpike（戴头上）→ 撞击冰块破坏 → 通过。

**关键设计点**：
- 年龄增速 **0.8**（最紧），逼玩家用加速 buff。
- 这一关操作压力大、谜题压力小，和 L3 形成节奏对比。
- 可拾取尖刺 + 冰块的组合是本关特色，强调"工具用法"。

### L5 —— 综合解谜关（新建 Level05）

**目标心智**：L2——回溯级联触发（机关→机关）。

**用到的机关**：水流、冰块、压力板、弹簧、尖刺发射器、可拾取尖刺（全部）。

**布局骨架**（多层，纵向+横向）：
```
              ┌── 出口(最顶层) ──┐
              │   ↑ 弹簧弹上来    │
   ┌──────────┴── 冰块墙 ────────┴──┐
   │  ↑ 回溯消融冰 → 水流下 → 触发压力板 → 发射器打碎上层冰
   │                                │
起点 ── 水源 ── 压力板A ── 尖刺发射器 ── 弹簧 ── ...
```

**核心谜题（级联回溯）**：
- 终点在高处，被冰块墙挡住。
- 打碎冰块需要尖刺发射器，发射器需要压力板 A 触发。
- 压力板 A 需要水流过来触发。
- 水源流下的水会结冰，结冰后不流动，压力板 A 不触发。
- **解法**：玩家回溯让冰消融 → 水流动 → 触发压力板 A → 发射器发射尖刺 → 打碎终点冰墙。但尖刺飞行需要时间，玩家可能要再回溯一次重置尖刺位置。

**关键设计点**：
- 这是全游戏最高密度谜题关，年龄增速 **0.7**（中等，给思考时间）。
- 不需要全部机关都用上，重点是**级联**这个心智。
- 可以考虑放一个"可选捷径"：如果玩家头戴可拾取尖刺，可以跳过部分流程直接破冰——奖励深度探索。

## 4. 整体流程与情绪曲线

```
难度/情绪
  │
高│                              ┌─L5综合(高潮)
  │                         ┌───┘
  │                    ┌──L4(操作紧张)
  │               ┌────┘
  │          ┌─L3(谜题深度)
  │     ┌────┘
  │  L2(死亡冲击)
低│L1(轻松教学)
  └────────────────────────────────────→ 关卡进度
```

- **L1→L2**：情绪陡升（从无压力到第一次死亡）。
- **L2→L3**：操作压力降，谜题压力升（让玩家喘口气用脑）。
- **L3→L4**：谜题降，操作升（节奏切换）。
- **L4→L5**：全面综合，难度高点。
