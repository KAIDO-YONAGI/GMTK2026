# 项目上手与构建

[返回项目介绍](../README.md) · [文档索引](README.md)

本文说明 Time Machine 的工程依赖、运行入口、按键操作与 Windows 构建。游戏内容、团队署名和资源许可见项目 README。

## 环境与依赖

使用 Unity Hub 安装 Unity Editor **2022.3.62f3c1**，并安装 Windows 构建支持。编辑器版本以 [ProjectVersion.txt](../ProjectSettings/ProjectVersion.txt) 为准。

主要依赖由 [Packages/manifest.json](../Packages/manifest.json) 声明：

| 依赖 | 版本 |
|---|---|
| Universal Render Pipeline | 14.0.12 |
| Cinemachine | 2.10.7 |
| Unity 2D 功能集 | 2.0.1 |
| TextMesh Pro | 3.0.7 |
| UGUI | 1.0.0 |
| Unity MCP | Git 标签 v10.0.0 |

Unity MCP 通过 GitHub Git URL 解析，首次导入需要 Git 命令可用且网络能够访问对应仓库。打开工程后由 Package Manager 按清单解析依赖。

工程使用旧 Input Manager，输入模式来源为 [ProjectSettings.asset](../ProjectSettings/ProjectSettings.asset) 的 `activeInputHandler`。

## 打开与运行

1. 在 Unity Hub 添加仓库根目录，使用对应版本的 Editor 打开。
2. 等待 Package Manager 完成依赖解析、资源导入与脚本编译。
3. 打开 `Assets/Scenes/InitialScene.unity` 并进入 Play Mode，从菜单进入游戏。

`InitialScene` 是工程启动入口，常驻场景承载跨关卡系统，内容场景组织菜单与关卡。场景加载和面板接入的开发参考见[场景加载与面板系统](场景加载与面板系统使用说明.md)。

## 操作

| 按键 | 功能 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| 空格 | 跳跃 |
| 按住 R | 时间回溯 |
| Esc | 暂停菜单 |
| 鼠标左键 | 拖动部分机关 |

## Windows 构建

1. 打开 `File > Build Settings`，选择 `PC, Mac & Linux Standalone`，目标平台使用 Windows，架构选择 x86_64。
2. 切换至目标平台，并保留仓库配置中的启用场景，确保 `InitialScene` 位于首项。
3. 选择 `Build`，指定输出目录并生成 Windows 可执行程序。
4. 分发时保留同次构建生成的程序、数据目录与随附运行库。

构建场景来源为 [EditorBuildSettings.asset](../ProjectSettings/EditorBuildSettings.asset)，启用列表包括：

| 场景 | 用途 |
|---|---|
| InitialScene | 启动入口 |
| StartingMenu | 标题菜单 |
| PersistentScene | 常驻场景 |
| PersistentScene_1 | 随工程构建的附加场景 |
| TeachingLevel01 | 教学关 |
| NormalLevel01 | 正式关卡 1 |
| NormalLevel02 | 正式关卡 2 |
