在线试玩：[Time Machine - itch.io](https://retraumend.itch.io/time-machine)

## 核心概念

`Time Machine` 是一款 Unity 2D 横版解谜与平台跳跃游戏，围绕一个残酷的构想展开：

**你的身体，就是倒计时本身，也是混乱的时间中你用于逃出轮回的消耗品。**

核心主题——**回溯改变过去，而未来正在衰老中耗尽**。

> *You can change the past and reach a better future, but your body won't stop counting down. No matter how bright what lies ahead, you will fade away in the flow of time…*

---

## 核心机制

### 衰老

- 年龄随现实时间实时增长，区间与增速可配置，每关独立设定
- 衰老不可逆，回溯期间照常流逝
- 随年龄增长，移速与跳跃力同步衰减，濒死阶段大幅减速
- 屏幕暗角随衰老进度逐渐加深，营造压迫感
- 到达年龄上限即老死（`OldDead`）；受伤致死为暴毙（`UnnormalDead`），两种结局对应不同的死亡提示
- 死亡后重开当前关卡，年龄重置

### 时间回溯

- 按住回溯键连续回溯，场景倒退至数秒之前
- 回溯窗口随年龄线性缩短：年轻时最长，老年时最短
- 回溯有消耗速率与冷却；回溯后获得短暂移速提升
- 交互性机关同步受回溯影响：水流、冰块、尖刺等状态均可回滚
- 回溯时身后拖出虚影剪影（对象池管理）

### 血量与生存

- 生命值由 HUD 心形显示，受伤带粒子与屏幕震动反馈
- 血量归零后进入濒死状态，可尝试回溯自救或艰难挪动寻找最后的机会
- 放弃自救则重开当前关卡

### HUD

- 回溯时间条（可用量 + 颜色渐变）
- 血量心形
- 濒死提示面板

## 机关系统

| 机关 | 说明 |
|------|------|
| **水流与冰块** | 触发器启动水流或结冰，水流按格子向下扩散并计时结冰。冰块可打破、可回溯；破碎后再次触发可重新计时结冰。冰块阻挡通行，水流不阻挡 |
| **尖刺发射器** | 操作环调整发射方向，支持连续/单次两种模式。发射的尖刺可被回溯收回 |
| **可拾取尖刺** | 拾取后用于破坏冰块 |
| **陷阱尖刺** | 接触即造成伤害 |
| **弹簧** | 竖直弹跳 |
| **压力板** | 踩下后触发绑定事件（如启动水流、打开门等） |
| **触发器** | 死亡区、关卡终点、导引区 |

## 技术栈

- **引擎**：Unity 2022.3.62f3c1 LTS
- **渲染管线**：Universal Render Pipeline (URP) 14.0.12
- **相机**：Cinemachine（Virtual Camera + Confiner2D + Camera Shake）
- **目标平台**：Standalone Windows 64-bit
- **2D 功能包**：com.unity.feature.2d 2.0.1
- **UI**：TextMesh Pro + Canvas (ScaleWithScreenSize, 1920×1080)

## 关卡设计

实装 3 关 + 2 个测试场景：

- **教学关**：回溯操作教学、穿墙过障碍
- **普通关 1**：死亡压力下的解谜
- **普通关 2**：流水结冰机关组合

解谜难度递进三个层次：

1. 回溯改变**自己**的位置与状态
2. 回溯改变**机关**状态（水 ↔ 冰、尖刺收回）
3. 回溯后**机关级联触发**
